# Vim で学ぶ Wikitext編集
Vimを使ったwikitextの編集を練習できる教材です。約1~2時間で学べます。

架空の都市「ヴェルダシア」に関するMediaWiki記法（wikitext）の記事を題材に、
Vim(neovim)を使いながら編集する練習をするための教材です。

## 使用するもの
- このファイル: ローカルへのダウンロードを推奨
- テキストエディタ: VS CodeやCursorなど。拡張プラグインとして、wikitextとneovim（neovimが編集できれば何でも可）をインストール。

## 進め方

各演習ファイルには `<!-- TASK: ... -->` という形でタスクが埋め込まれています。

- ファイルを開き、TASKコメントを上から順に読みながら指示された編集をVimコマンドで行う
- TASKコメント自体は最後に削除してOK（`dd` や `d/-->` の練習にもなります）
- 各モジュールの答えは `solutions/` フォルダにあります。詰まったら覗いてOKですが、まずは5分は自力で粘ってみましょう
- マウスやキーボードの矢印キーはできるだけ使わず、Vimのモーション（`hjkl`、`w`/`b`/`e`、`f`/`t` など）だけで移動する縛りにすると練習効果が高いです

`cheatsheet.md` に今回使うコマンド一覧をまとめているので、作業中は別ペインに開いておくと便利です。

## 参考
### wikitextの最低限の記法（参考）

- 見出し：`== 見出し ==`（`=`の数でレベルが変わる）
- 太字：`'''太字'''` / 斜体：`''斜体''` / 太字+斜体：`'''''両方'''''`
- 内部リンク：`[[記事名]]` / 表示文字付き：`[[記事名|表示文字]]`
- 外部リンク：`[https://example.org 表示文字]`
- テンプレート：`{{テンプレート名|引数1|引数2}}`
- 箇条書き：`* 項目`（番号付きは `# 項目`）
- 表：`{| ... |- ... | セル ... |}`

### Cursorを使う場合のセットアップ

1. Cursorを開く
2. `Cmd+Shift+P` → `Preferences: Open Settings (JSON)` を選択
3. 以下を追加して保存
   ```json
   "vim.enable": true
   ```
   もし反映されない場合は、拡張機能タブで `Vim`（vscodevim.vim）を検索してインストールしてください。CursorはVSCodeベースなので同じ拡張機能が動きます。
4. 画面左下に `-- NORMAL --` のようなVimモード表示が出ればセットアップ完了です
5. このフォルダ（`vim_wikitext_practice`）をCursorで開いてください（File > Open Folder）
